How it works

Real history, not an estimate.

commit.city does not guess from contribution counts. It reads git itself and replays what happened to every file, so a tower is exactly as tall as that file was on that day.

Discover

GitHub's GraphQL API finds the repos and, for a person, which commits are theirs. A whole city costs a handful of API points.

Replay

The builder speaks git's own wire protocol to GitHub, fetches only the history packs it needs, and replays the default branch commit by commit: every path, every line count, every rename.

Render

The viewer turns that into instanced three.js geometry with bloom, a day-night sky and a scrubbable timeline, around 60 fps on a laptop and adaptive on phones.

Private repos and self-hosting

Run it yourself. Your token never leaves your repo.

commit.city only ever reads public data. For a city that includes private work, run the same open-source pipeline in your own GitHub Actions or on your laptop. It publishes one self-contained HTML page and private repos are anonymised by default.

GitHub Action

Click Use this template on the repo, enable Pages, and run the workflow. It rebuilds weekly, and only repos with new commits are fetched again.

# .github/workflows/commit-city.yml
- uses: azank1/commit-city@v0
  with:
    token: ${{ secrets.COMMIT_CITY_TOKEN || github.token }}

Command line

Python 3.11+ and git. It writes one HTML file you can open offline or host anywhere, and picks up your gh login if you have one.

pipx install git+https://github.com/azank1/commit-city
commit-city build --login you --include-private
# -> commit-city.html
FAQ

Questions.

What data does it read? Is my code stored?

Public repositories only. Commit times and authors come from GitHub's API; file paths and line counts come from replaying git history over GitHub's git protocol. No source code is stored, only paths, line counts and times, the same things anyone can see on GitHub. Cities and repo records are cached so the next visitor gets them instantly.

How do I hide my city, or leave a repo out?

Open your city, press Share, then Sign in with GitHub. Sign-in requests no permissions. Untick repos to leave them out, or hide your city and your repo cities entirely. Org owners who want an org city hidden can open an issue.

Why are my numbers lower than my contribution graph?

GitHub's graph also counts pull requests, issues, reviews and private contributions. A city draws commits that landed on the default branch of a public repo, because those are the ones that changed the code you can see.

What are the limits?

People get up to 50 repos, orgs their 24 busiest. The hosted builder skips repos over 1.5 GB, and very large cities fold the deepest directories into blocks so the browser stays smooth. The CLI and Action have no such limits.

Why is the first build slow?

It replays real git history from GitHub, and big repos take a minute or two. Every repo record is shared between cities, so popular repos are usually already cached, and your next rebuild only replays what changed.
